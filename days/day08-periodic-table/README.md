# Day 8: Periodic-table property lookup

**What:** An offline command-line lookup for the 118 elements: look one up by symbol, name or atomic number, list elements by group, period, block or category, pull out a single property for scripts, or get the molar mass of a formula.
**Why:** Atomic masses, electronegativities and radii come up constantly: molarity and yield calculations, choosing a basis set or a covalent radius, checking where a dopant sits in the table. This avoids opening a browser mid-calculation.

## Usage
One element (symbol, name or atomic number, any capitalization; `sulphur`, `aluminium` and `caesium` work too):
```bash
python tool.py Fe
```
```
Fe  Iron  (Z = 26)
  group / period        8 / 4   (d-block, Transition metals)
  atomic mass           55.845 u
  electronegativity     1.83 (Pauling)
  electron config.      [Ar] 3d6 4s2
  covalent radius       116 pm
  van der Waals radius  244 pm
  melting point         1811.15 K
  boiling point         3134.15 K
  density               7.87 g/cm3
```
A typo gets a suggestion: `python tool.py iorn` prints `unknown element 'iorn'. Did you mean Iron?`

List elements with filters (they combine):
```bash
python tool.py --group 17
python tool.py --block d --period 4 -o 3d_metals.csv      # also saves every column as CSV
python tool.py --category "noble gases"
```
```

9    F    Fluorine    18.998403  17   2    p    3.98  Halogens
17   Cl   Chlorine    35.45      17   3    p    3.16  Halogens
35   Br   Bromine     79.904     17   4    p    2.96  Halogens

85   At   Astatine    210        17   6    p    2.2   Halogens
117  Ts   Tennessine  294        17   7    p    n/a   Halogens
```
One property for scripts (aliases: `mass`, `en`, `mp`, `bp`, `density`, `covalent`, `vdw`, `config`, `z`):
```bash
python tool.py O --property en          # 3.44
python tool.py Cu Zn --property mass    # Cu<TAB>63.546 and Zn<TAB>65.38
```
Molar mass of a formula, with the mass percent of each element. Parentheses, brackets and hydrates are understood:
```bash
python tool.py --formula "CuSO4.5H2O"
```
```
CuSO4.5H2O: 249.677 g/mol
  Cu x 1      63.546 g/mol   25.45 %
  S  x 1      32.060 g/mol   12.84 %
  O  x 9     143.991 g/mol   57.67 %
  H  x 10     10.080 g/mol    4.04 %
```
Formulas are case-sensitive, as in chemistry: `CO` is carbon monoxide and `Co` is cobalt.

## Data and license
The table is `elements.csv`, generated by `make_data.py` from the [mendeleev](https://github.com/lmmentel/mendeleev) package (version 1.3.0), which is MIT licensed, Copyright (c) 2015 Lukasz Mentel. Its license text is in `MENDELEEV_LICENSE.txt`. If you reuse this table, keep that notice.

| Column | Notes |
|---|---|
| atomic_mass | in u (g/mol), as compiled by mendeleev |
| electronegativity | Pauling scale |
| covalent_radius_pm | single-bond radii, Pyykko and Atsumi, *Chem. Eur. J.* 2009, 15, 186 |
| vdw_radius_pm | Alvarez, *Dalton Trans.* 2013, 42, 8617 |
| melting / boiling point, density | as compiled by mendeleev; see its documentation for the original sources |
| group, period, block, category | position and series as given by mendeleev |

To rebuild the table (not needed for normal use): `pip install mendeleev && python make_data.py`.

## Test
```bash
pytest days/day08-periodic-table
```
The tests check the table is complete (Z = 1 to 118, unique symbols), spot-check values (C 12.011, Fe 55.845, Au 196.966569, O 3.44), lookups and spellings, the filters, formula parsing (nested brackets and hydrates, bad input) and each command. The aspirin molar mass matches Day 3.

## Limitations
- Missing values show as `n/a` (for example the electronegativity of most superheavy elements, and the melting point of carbon, which sublimes).
- For elements with no stable isotope (Tc, Pm, Po to Ra, Np and heavier) the mass is that of a long-lived isotope, not an IUPAC standard atomic weight. Treat those as approximate.
- Ce to Lu and Th to Lr have no group number in this table, so `--group` does not list them. Use `--block f` or `--category lanthanides`.
- Melting and boiling points are for the pure element at normal pressure. Some elements have several allotropes, so check the source for precise work.
- Only the molar mass of a formula is computed. Charges and isotopes (like `13C`) are not supported.
